# 段階Q セットアップ手順（資格情報の詳細化・期限アラート）

SmartHR「従業員の資格一覧」エクスポートを資格データの正にする。
- **タグ（簡易）**：保有資格から「1級/2級 施工管理技士」を自動導出 → 資格軸ガント・バッジで使用（建築/土木等は畳む・技士補は除外）
- **詳細**：監督ダッシュボードに種別ごとに全量表示＋取得日/有効期限＋**期限アラート**（期限切れ=赤/残30日=橙/残90日=黄）

## 事前準備（あなた）

1. **SmartHR で全監督分の「従業員の資格一覧」をエクスポート**（今回の4名分ではなく全員分）。
   - 必要列：社員番号・氏名・コード・保有資格・取得日・有効期限（他の列＝部署/点数/資格番号/証明書の写し 等はあっても無視されます）
   - **社員番号は organization（名簿）と一致必須**。

## カットオーバー手順（コードとDBを同時に切替）

> ⚠️ 順序厳守。DBスキーマだけ先に変えると本番の資格表示が一時的に空になります。

1. **`02_employees` タブにエクスポートを貼付**（ヘッダ行含めそのまま・既存の旧データは消して置換）。
2. **`feature/qualifications` を main にマージ＆push**（新コードが新スキーマを読む状態に）。
3. **`phaseQ_employee_quals.sql` を Supabase SQL Editor で実行**（employee_quals を新スキーマに作り直し）。
4. GitHub Pages 反映後、**admin でログイン →「同期」**（02_employees → employee_quals 全置換）。
5. 確認：
   - 監督ダッシュボードで対象者を選ぶ → 保有資格が種別ごとに表示・期限アラートが出る
   - 資格軸ガント・バッジが「1級/2級 施工管理技士」だけで切り分く

## ロールバック

- main を戻す ＋ `phaseD5_schema.sql`（旧スキーマ）再作成 ＋
  `besterra-allocation-backups/2026-05-26_supabase/employee_quals.json`（旧109行）を投入。

## 今後の更新運用

- SmartHR で資格を更新 → 再エクスポート → `02_employees` に貼り替え → admin で「同期」→ 即反映。
- 期限切れ/間近はダッシュボードに自動表示（しきい値は sync.js `qualExpiryStatus` で変更可）。
